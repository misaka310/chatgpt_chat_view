# Dashboard Guide

`dashboard.html` は、ChatGPT export と Codex ログの活動量を読むためのローカル画面です。

## 読む順番

1. まず `dashboard_summary.json` を読み込んで、全体サマリーと月別サマリーを表示します。
2. 月別サマリーの「詳細」を開くと、その月の1日ごとの会話数一覧が表示されます。
3. 日別一覧を見るだけなら日付選択は不要です。
4. 日付選択が必要なのは、その日の上位会話や時間帯別の掘り下げです。
5. 会話一覧が必要なときだけ `dashboard_conversations.json` を読み込みます。
6. カテゴリやキーワードを見たいときは `dashboard_categories.json` を読み込みます。
7. Codex 照合を見たいときは `dashboard_codex_match.json` を読み込みます。

## 画面の見方

- `読み込み中` は、今どの JSON を読んでいるかを示します。
- `件数` は、読み込んだデータの総数です。
- `表示中の範囲` は、会話一覧や Codex 一覧で今描画している件数を示します。
- 会話一覧はページング表示なので、最初は少ない件数だけ描画されます。
- エラーは画面上に出ます。ファイルを直接開いて失敗する場合は、ローカルHTTPサーバー経由で開いてください。

## 注意

- 初期表示では大きな詳細データは読み込みません。
- `dashboard.html` を直接ダブルクリックすると、`fetch()` 制約で JSON を読めないことがあります。
- 月別サマリーの「詳細」は月内の日別一覧の入口であり、日付選択の入口ではありません。
