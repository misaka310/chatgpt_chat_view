# Dashboard Guide

`start.bat` を実行すると、必要に応じて解析したあと、`output/dashboard.html` がローカルHTTPサーバー経由で開きます。

## 読む順番

1. ルートの `start.bat` をダブルクリックします。
2. 最初に「最新月の送信数」と月別・日別の推移を確認します。
3. 連続3時間の送信数候補を見る場合は、画面内の「3時間160チェック」リンクを開きます。

## 画面の構成

- `dashboard.html`: 月別・日別の送信数と推定トークン数
- `gpt_3h_limit.html`: 任意の連続3時間におけるユーザー送信数の候補値
- `dashboard_summary.json` / `dashboard_daily.json`: ダッシュボードが読み込む集計データ

## 起動中の注意

ブラウザ表示には `127.0.0.1` のローカルHTTPサーバーを使用します。ダッシュボードを見ている間は、`start.bat` が開いたコマンドウィンドウを閉じないでください。使い終わったらウィンドウを閉じるとサーバーも停止します。

## 集計値の注意

- 公式のモデル別利用量ではありません。
- ChatGPTエクスポート内のユーザー送信を数えた候補値です。
- モデル、Thinking、添付、ツール利用を正確には分離できません。
